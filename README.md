# AI Telegram Bots Orchestrator

Система из 3 телеграм ботов, которые имитируют рабочий чат между заказчиком, проект-менеджером и разработчиком.

## Возможности

- Генерация реалистичных диалогов с помощью OpenAI GPT-4
- 3 бота с уникальными личностями и ролями
- Имитация естественной печати с задержками
- **Веб-интерфейс для управления** (НОВОЕ!)
- **REST API на FastAPI** (НОВОЕ!)
- Интерактивный CLI режим
- Настраиваемые сценарии диалогов

## Установка

### 1. Клонируйте репозиторий
```bash
cd /путь/к/проекту
```

### 2. Установите зависимости
```bash
pip3 install -r requirements.txt
```

### 3. Создайте телеграм группу

1. Откройте Telegram и создайте новую группу
2. Добавьте всех трех ботов в группу:
   - `@YourPMBotName` (Project Manager)
   - `@YourDeveloperBotName` (Developer)
   - `@YourClientBotName` (Client)

### 4. Получите Chat ID

Вы можете получить ID чата несколькими способами:

#### Способ 1: Через @RawDataBot
1. Добавьте бота @RawDataBot в вашу группу
2. Он отправит информацию о чате
3. Найдите `"id": -1234567890` - это ваш Chat ID

#### Способ 2: Через API
1. Отправьте любое сообщение в группу
2. Откройте в браузере:
   ```
   https://api.telegram.org/bot<TOKEN>/getUpdates
   ```
   Замените `<TOKEN>` на токен любого из ваших ботов
3. Найдите `"chat":{"id":-1234567890}` в ответе

### 5. Настройте .env файл

Откройте файл `.env` и добавьте Chat ID:

## Использование

### Веб-интерфейс (Рекомендуется!)

Самый простой способ управления системой через браузер:

```bash
python3 start_server.py
```

Затем откройте в браузере: **http://localhost:8000**

Веб-интерфейс предоставляет:
- Удобную форму для ввода промпта
- Настройку параметров (количество сообщений, Chat ID)
- Мониторинг статуса ботов в реальном времени
- Просмотр сгенерированного сценария
- Красивый и интуитивный UI

**API документация**: http://localhost:8000/docs

### CLI Интерактивный режим

```bash
python3 main.py
```

После запуска вы увидите меню с командами:

```
1. run     - Запустить полный цикл (генерация + выполнение)
2. generate - Только сгенерировать сценарий
3. show    - Показать текущий сценарий
4. execute - Выполнить текущий сценарий
5. check   - Проверить состояние ботов
6. help    - Показать меню
7. exit    - Выход
```

### Быстрый запуск

```bash
python3 main.py --quick
```

Запустит систему с дефолтным сценарием.

## Настройка

### config.py

Вы можете настроить:

- `MODEL_NAME` - модель OpenAI (по умолчанию "gpt-4")
- `MAX_MESSAGES` / `MIN_MESSAGES` - количество сообщений в диалоге
- `MIN_DELAY` / `MAX_DELAY` - задержки между сообщениями (секунды)
- `TYPING_SPEED` - скорость печати (символов/секунду)
- `BOT_PERSONALITIES` - личности ботов

### Пример изменения личностей

Отредактируйте `config.py`:

```python
BOT_PERSONALITIES = {
    "pm": {
        "name": "Александр (PM)",
        "role": "Project Manager",
        "personality": "Твоя кастомная личность..."
    },
    ...
}
```

## Troubleshooting

### Ошибка: "Не все боты доступны"
- Проверьте токены в `.env`
- Убедитесь что боты активны в BotFather

### Ошибка: "Ошибка отправки сообщения"
- Проверьте `TARGET_CHAT_ID`
- Убедитесь что боты добавлены в группу
- Проверьте что боты не заблокированы

### Ошибка: "OpenAI API error"
- Проверьте `OPENAI_API_KEY` в `.env`
- Убедитесь что у вас есть доступ к GPT-4 (или измените модель на gpt-3.5-turbo)

### Боты не отвечают в группе
- Убедитесь что у ботов включен режим "Privacy Mode: Disabled" в BotFather
- Или сделайте ботов администраторами группы

## Как получить токены ботов (если нужны новые)

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен и добавьте в `.env`
5. Отключите Privacy Mode: `/setprivacy` -> выберите бота -> Disable
