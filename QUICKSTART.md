# Быстрый старт (Quick Start)

## 🌐 Веб-интерфейс (Самый простой способ!)

### Если у вас уже настроен Chat ID:

```bash
python3 start_server.py
```

Откройте в браузере: **http://localhost:8000**

Готово! Управляйте ботами через красивый веб-интерфейс.

---

## 📱 Первичная настройка

### Шаг 1: Проверка ботов

```bash
python3 test_bots.py
```

Вы должны увидеть, что все 3 бота подключены:
- @nyro_project_manager_bot (PM)
- @new_ai_agent_test_bot (Client)
- @nyro_developer_bot (Developer)

## Шаг 2: Создание Telegram группы

1. Откройте Telegram
2. Создайте новую группу (назовите, например, "AI Test Chat")
3. Добавьте всех трех ботов:
   - @nyro_project_manager_bot
   - @new_ai_agent_test_bot
   - @nyro_developer_bot

## Шаг 3: Отключение Privacy Mode (ВАЖНО!)

Чтобы боты могли видеть сообщения в группе:

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/setprivacy`
3. Выберите бота
4. Нажмите **Disable**
5. Повторите для всех трех ботов

## Шаг 4: Получение Chat ID

```bash
python3 get_chat_id.py
```

**ПЕРЕД запуском**: отправьте любое сообщение в группу!

Скрипт покажет Chat ID, например: `-1001234567890`

## Шаг 5: Настройка .env

Откройте `.env` и добавьте полученный Chat ID:

```env
TARGET_CHAT_ID=-1001234567890
```

## Шаг 6: Запуск!

### Вариант A: Веб-интерфейс (Рекомендуется!)

```bash
python3 start_server.py
```

Откройте: **http://localhost:8000**

1. Введите промпт или выберите пример
2. Нажмите "Запустить полный цикл"
3. Наблюдайте как боты общаются в группе!

### Вариант B: CLI режим

```bash
python3 main.py
```

В меню выберите:
```
> 1  # run - полный цикл
> Создай диалог про разработку сайта для кофейни  # ваш промпт
> 25  # количество сообщений (Enter для авто)
> [Enter]  # использовать Chat ID из .env
```

## Готово!

Боты начнут общаться в вашей группе!

## Troubleshooting

### "Не все боты доступны"
→ Проверьте токены в `.env`

### "Ошибка отправки сообщения"
→ Проверьте `TARGET_CHAT_ID` и что боты в группе

### "OpenAI API error"
→ Проверьте `OPENAI_API_KEY` в `.env`

### Боты не видят сообщения
→ Отключите Privacy Mode через @BotFather (см. Шаг 3)
