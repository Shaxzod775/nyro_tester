# Веб-интерфейс - Руководство пользователя

## Быстрый старт

### 1. Запуск сервера

```bash
python3 start_server.py
```

Вы увидите:
```
🚀 Запуск веб-сервера...

📱 Веб-интерфейс: http://localhost:8000
📚 API документация: http://localhost:8000/docs
```

### 2. Открыть в браузере

Перейдите по адресу: **http://localhost:8000**

## Интерфейс

### Левая панель: Создание диалога

1. **Описание сценария**
   - Введите промпт, описывающий желаемый диалог
   - Примеры доступны ниже формы (кликните для выбора)

2. **Количество сообщений** (опционально)
   - Оставьте пустым для автоматического выбора (20-35)
   - Или укажите конкретное число (10-50)

3. **Chat ID** (опционально)
   - Если пусто, используется из `.env` файла
   - Можно переопределить для другой группы

4. **Кнопка "Запустить полный цикл"**
   - Генерирует сценарий и отправляет в Telegram группу

### Правая панель: Статус системы

Отображает статус всех трех ботов:
- **PM Bot** (Проект-менеджер)
- **Developer Bot** (Разработчик)
- **Client Bot** (Заказчик)

Статусы:
- **Зеленый** - Бот онлайн
- **Красный** - Бот недоступен

### Нижняя панель: Текущий сценарий

Показывает сгенерированный сценарий:
- Имя агента
- Текст сообщения
- Порядковый номер

## Примеры использования

### Пример 1: Простой запуск

1. Нажмите на пример: "Создай диалог про разработку мобильного приложения для фитнеса"
2. Нажмите "Запустить полный цикл"
3. Наблюдайте как боты отправляют сообщения в группу!

### Пример 2: Кастомный сценарий

1. Введите свой промпт: "Обсуждение создания онлайн-школы с видеокурсами"
2. Укажите 30 сообщений
3. Нажмите "Запустить полный цикл"

### Пример 3: Разные группы

1. Получите Chat ID другой группы через `get_chat_id.py`
2. Введите новый Chat ID в поле
3. Запустите сценарий

## API Endpoints

Веб-интерфейс использует REST API на FastAPI:

### GET `/api/health`
Проверка здоровья API

### GET `/api/status`
Получить статус ботов

**Ответ:**
```json
{
  "bots": {
    "pm": {
      "name": "Алексей (PM)",
      "username": "@nyro_project_manager_bot",
      "status": "online"
    },
    ...
  },
  "is_running": false,
  "has_scenario": true
}
```

### GET `/api/scenario`
Получить текущий сценарий

### POST `/api/generate`
Только сгенерировать сценарий (без выполнения)

**Body:**
```json
{
  "prompt": "Создай диалог...",
  "num_messages": 25
}
```

### POST `/api/execute`
Выполнить текущий сценарий

**Body:**
```json
{
  "chat_id": -1001234567890
}
```

### POST `/api/run`
Полный цикл: генерация + выполнение

**Body:**
```json
{
  "prompt": "Создай диалог...",
  "num_messages": 25,
  "chat_id": -1001234567890
}
```

### GET `/api/config`
Получить текущую конфигурацию системы

## Troubleshooting

### Сервер не запускается

**Ошибка**: `Address already in use`

**Решение**: Порт 8000 уже занят. Измените порт в `start_server.py`:
```python
uvicorn.run("api:app", port=8001)  # Используем 8001
```

### Боты не реагируют

1. Проверьте статус на панели справа
2. Нажмите "Обновить статус"
3. Проверьте токены в `.env`
4. Убедитесь что Chat ID правильный

### Сценарий не генерируется

1. Проверьте `OPENAI_API_KEY` в `.env`
2. Убедитесь что у вас есть баланс на OpenAI
3. Проверьте доступ к модели GPT-4 (или измените на gpt-3.5-turbo в `config.py`)

### Ошибка Chat ID

**Ошибка**: `Chat ID не установлен`

**Решение**:
1. Запустите `python3 get_chat_id.py`
2. Добавьте Chat ID в `.env`
3. Перезапустите сервер

## Дополнительные возможности

### Запуск на другом хосте

По умолчанию сервер доступен на всех интерфейсах (`0.0.0.0`). Для доступа с других устройств в локальной сети:

1. Узнайте IP вашего компьютера: `ifconfig` (Mac/Linux) или `ipconfig` (Windows)
2. На другом устройстве откройте: `http://YOUR_IP:8000`

### Production деплой

Для production используйте:

```bash
uvicorn api:app --host 0.0.0.0 --port 8000 --workers 4
```

Или с Gunicorn:

```bash
gunicorn api:app -w 4 -k uvicorn.workers.UvicornWorker --bind 0.0.0.0:8000
```

### HTTPS (опционально)

Для HTTPS используйте nginx в качестве reverse proxy или Cloudflare Tunnel.
